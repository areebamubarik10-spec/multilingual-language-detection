# Multilingual Language Detection Using Machine Learning

### Project Overview
A comparative analysis of machine learning algorithms for detecting languages from text using character-level TF-IDF features.

### Dataset
- 22 languages
- 22,000 text samples

### Technologies
Python, Scikit-learn, Pandas, NLP, TF-IDF, Matplotlib

### Models
- Naive Bayes
- Logistic Regression
- Linear SVC

### Results
Linear SVC achieved 98.77% test accuracy.

### Evaluation
Models were evaluated using accuracy, precision, recall, F1-score, and a confusion matrix.
